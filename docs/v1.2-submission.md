## What's New

```
Categories are yours now.

• File any recipe where you want it — add a category Dilla missed, remove one it guessed wrong. Your choice sticks, on every recipe.
• More recipe sites work on the first try, including several big ones that used to fail outright.
• Video recipes now capture the whole ingredient list. Long captions were being cut short, so amounts went missing — they don't any more.
• Reels behind an age check import instead of stopping.
• The intro now shows you exactly which button to tap to send a recipe to Dilla, instead of just describing it.
```

Publishers are deliberately unnamed: naming third parties in store metadata
invites complaints and tells the user nothing extra.
